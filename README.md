# Xirp archive handoff

This private repository holds the unchanged `xirp.zip` archive as four numbered parts because GitHub's browser uploader has a per-file size limit. Join the parts in name order to recover the exact original archive. The archive expands to a top-level `xirp/` directory and includes bundled dependencies, build output, and local application data.
